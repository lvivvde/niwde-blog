## 2026-10-31

### Data：训练数据

今天学习了课程中的数据部分。这一节没有太多疑问，主要记录讲义中的核心内容。

#### 数据为什么重要

数据并不是天然存在、拿来就能训练的。大模型的能力不仅取决于模型结构和参数量，也很大程度上取决于训练数据的内容、质量与配比。不同模型之间的差异，有相当一部分来自数据处理方案。

训练通常会从覆盖面广但质量参差的预训练数据，逐步转向规模更小、质量更高的数据，最后再使用对话、偏好等数据进行后训练。

#### 数据从哪里来

- **Common Crawl**：大规模网页抓取数据，覆盖面很广，但噪声较多，需要大量清洗。
- **Wikipedia**：质量相对较高，包含多语言和通用知识。
- **GitHub**：提供代码、Issue 和 Pull Request 等内容，但需要处理重复仓库、Fork 和开源许可证。
- **arXiv、图书与问答网站**：可以补充论文、专业知识、长文本和高质量问答。

“使用整个互联网训练”并不准确。爬虫只能获取允许访问并且能够抓取的内容，动态页面、登录限制、付费墙、`robots.txt` 和服务条款都会限制数据获取。

#### 从原始内容到训练数据

大致流程是：

> 内容抓取 → 正文提取 → 语言识别 → 质量过滤 → 去重 → 安全与合规检查 → 数据混合与采样 → Token 化

其中，正文提取负责从 HTML 中去掉导航栏、广告等无关内容；质量过滤用于排除乱码、垃圾文本和低质量页面；去重可以避免同一内容被反复学习；还需要防止测试题进入训练集，造成基准测试污染。

不同来源的数据通常不会直接等量混合，而是根据质量和训练目标设置不同的采样权重。

#### 法律与伦理问题

公开可访问不等于可以随意用于训练。构建数据集时还要考虑版权、许可证、网站服务条款、隐私和有害内容。相关法律仍在发展，因此数据的来源和处理过程需要尽可能清晰、可追踪。

#### 核心结论

- 数据收集和清洗本身就是大模型训练的重要工程。
- 数据质量、覆盖范围和混合比例会直接影响模型的能力与偏差。
- 网页数据规模很大，但必须经过正文提取、过滤和去重。
- 高质量数据并不一定很多，如何筛选和重复利用它们非常重要。
- 数据处理流程仍大量依赖经验规则，还有很大的优化空间。
